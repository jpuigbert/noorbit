NoOrbit × Claude Code Game Studios

Plantilla i flux per crear jocs de navegador a partir d'una idea, dins de NoOrbit, compatible amb totes les IA connectades.

Com començar

  1. Descarrega NoOrbit: Releases.
  2. Fitxer → Nou projecte → pestanya Game Studios (clona la plantilla).
  3. Obre el panell Agent i tria la IA (local o núvol).
  4. Escriu: /prototype un joc de pesca on el peix rar només pica a la posta de sol.

Dreceres (shortcuts) per IA

Flux base (totes les IA)

  • /prototype <idea>
  • Respon les preguntes («tu tries» funciona).
  • Revisa design/game-brief.md → «Construeix-lo».
  • Joc a prototypes/<nom>/.

IA local (Ollama / llama.cpp)

  • Gestor de models → tria el model actiu.
  • Recomanat per a proves ràpides.
  • «construeix-lo a mitjà» per a models petits.

IA al núvol

  • IA ▸ Gestor de models → connecta el token.
  • OpenAI, Claude, Gemini, DeepSeek, Qwen, GLM, Grok…
  • Millor qualitat per al primer build.

IA de web

  • Panell «IA de web» → pregunta (amb permís).
  • NoOrbit extreu el codi i el materialitza.

Imatges i assets

  • ComfyUI local o via API.
  • Nudge «IMG|» si la IA respon amb prosa.
  • Enganxa imatges al xat (⌘V).

3D (Blender / Unreal)

  • Game Studios es centra en navegador.
  • Per a 3D, usa els panells Blender/Unreal.

Després

  • Canvia-ho preguntant: cada canvi es comprova; acceptat = punt de control.
  • Comparteix-ho: còpia neta per a itch.io o enllaç.
  • Fes-lo créixer: Vite + TypeScript, una funció per sessió; /create-stories, /dev-story, /story-done.
  • Acaba'l: /cut proposa què tallar i data de venda.

Jam autònom — l'agent treballa sol (i el Mac no es penga)

La Jam deixa la IA desenvolupar el projecte durant hores: fa un pla, escriu codi, el materialitza, el verifica i commiteja cada pas.

  • Agent ▸ pestanya Jam (o IA ▸ Jam autònom).
  • Brief → «Fes el pla» → «Comença». Motor: Godot 4, Blender, Unreal 5, Unity o web.
  • Usa la IA que tinguis connectada: local (Ollama/llama.cpp) o núvol (OpenAI, Claude, Gemini, DeepSeek, GLM, Grok…).
  • Memòria: si una tasca consumeix massa, s'atura i es reintenta amb menys qualitat — el Mac no es congela.
  • Al final: REPORT.md amb el pla, els resultats i els commits.

Models lliures a l'edge (cost 0) + smolmaxxing

Models GGUF de pesos oberts que es fan córrer localment (cost 0). Per a dispositius amb ~1 GB de RAM, usa smolmaxxing (pedaç de llama.cpp).

  • IA ▸ Hugging Bay → baixa un GGUF (Qwen3.5-0.8B/2B, SmolLM3 3B, Gemma 3 4B…).
  • IA ▸ Gestor de models → motor local (llama.cpp) registra el proveïdor sense clau.
  • Per a smolmaxxing: compila el build pedaçat i apunta NoOrbit al binari.
